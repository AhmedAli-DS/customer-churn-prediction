# Customer Churn Prediction

This project predicts customer churn for a telecommunications company using machine learning.

## Project Overview

- Dataset: Telco Customer Churn dataset  
- Goal: Predict whether a customer will leave the service (churn) or stay  
- Approach: Data preprocessing, encoding, scaling, and modeling using Logistic Regression and Decision Tree Classifier

## Technologies Used

- Python 3  
- Pandas  
- NumPy  
- Scikit-learn  

## How to Run This Project

```bash
git clone https://github.com/AhmedAli-DS/customer-churn-prediction.git

Install required packages:

Results
